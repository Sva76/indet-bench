# Reasoning models, part B, 16 November 2026 (exploratory)

Archived output of `notebooks/IndetBench_reasoning_v2.ipynb` (R-notebook-2), mode *completo*, on the frozen prose benchmark (set PN, 800 B/C pairs), with reasoning switched on (and, for Qwen3-8B, also off with the same weights). Report: [`docs/REASONING_PART_B_RESULTS_2026-11-16.md`](../../docs/REASONING_PART_B_RESULTS_2026-11-16.md); Italian original, v2, approved by the owner on 16 Nov 2026: [`Risultati_parteB_reasoning_v2.md`](Risultati_parteB_reasoning_v2.md). Protocol: [`docs/REASONING_PART_B_PROTOCOL.md`](../../docs/REASONING_PART_B_PROTOCOL.md).

- One folder per model (`<key>-<fingerprint>/`): `punteggi.csv` (per-row scores; Qwen3-8B has 1600 rows per condition, `condizione` = `acceso`/`spento`), `esito.json` (full report, including `report_indetbench` per condition, baselines, controls and, for Phi-4-reasoning, `memoria_cuda`), `manifest.json` (model, revision, dtype, GPU, package versions, commit, sampling), `ragionamenti.csv` (full reasoning text per row), `ripetibilita.csv` (two extra seeds on the first 20 stories, with reasoning text), `anomalie.csv`, `scarti_lunghezza.csv`.
- `riepilogo.csv/json`, `rapporto.txt`: summary as produced by the notebook in the second session (Italian). `controllo_cpu_testU2.json`: CPU check of the four Test U2 values.
- `ricalcolo_parteB.py`: the independent recomputation of W used for the report, kept as run.
- Two sessions on an A100-SXM4-40GB. The first completed Qwen3-8B and R1-Distill-Llama-8B; Phi-4-reasoning stopped at 1152/1600 rows with a CUDA out-of-memory error. The second, with `notebooks/IndetBench_reasoning_v2_1.ipynb` (memory handling only, same fingerprint), skipped the two completed models and resumed Phi-4 from its saved blocks. Qwen3-8B and R1 files are byte-identical in the two archives; Phi-4's 1152 rows from the first session are identical in the final scores. Archived here: the second session's archive `indetbench_reasoning_completo.zip`, SHA-256 `5c334288d70e712d9f8eb0c21fbbd3c65c1661909579cbc363746ec04bb8dd90` (held by the owner); first session `ce7335b2e306bd917b25f872b7b422324913357a27901954a2f56fc34a283d21`. Not included: per-block checkpoints and nested ZIPs (same content).
- Qwen3-32B was not run (needs the A100-SXM4-80GB).
- Integrity: `SHA256SUMS`; `tests/test_reasoning_part_b_results.py` recomputes W, intervals, gate and verdict from `punteggi.csv` for the four model × condition results.
- Model licences: Apache 2.0 (Qwen3-8B), MIT (Phi-4-reasoning), MIT for DeepSeek-R1-Distill-Llama-8B, which is derived from Llama-3.1-8B, so the Llama 3.1 Community License also applies to the model. No weights are stored here. The reasoning texts and answers are model outputs, not covered by the repository licence (see [`docs/THIRD_PARTY.md`](../../docs/THIRD_PARTY.md#model-outputs)).
